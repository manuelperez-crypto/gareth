Connect your contact form to n8n + Claude

Right now your form emails through formsubmit.co. This routes it through an n8n workflow instead, so every submission automatically gets a reply drafted by Claude and lands in your inbox. About 15 minutes.

1Get n8n runningyou

n8n is where the workflow lives. Pick one:

  • Easiest — n8n Cloud: sign up at n8n.io and start the free trial. Nothing to install.
  • Self-host (free): run docker run -it --rm -p 5678:5678 n8nio/n8n, then open http://localhost:5678. (For the webhook to be reachable by your live site it needs a public URL — Cloud is simpler for that.)
2Import the workflow

In n8n: top-right ⋯ menu → Import from File, and choose nexum-contact-workflow.json (the file included alongside this guide). You'll see four connected nodes: Webhook → Claude → Email → Respond.

3Add your Anthropic API keyyou

Open the "Claude — draft reply" node. Under Header Parameters, find x-api-key and replace YOUR_ANTHROPIC_API_KEY with your real key from console.anthropic.com.

Keep the key private. It's in the workflow, not in your website — so it never reaches the browser. Don't paste your key into the HTML or commit it to the repo.
4Connect your emailyou

Open the "Email the lead to you" node, connect your Gmail account (or swap it for the SMTP Send Email node), and change you@nexum.com to the inbox where you want leads. The email includes the lead's details and Claude's suggested reply.

5Copy the webhook URL & update the form

Open the Webhook node and copy its Production URL (looks like https://your-n8n-host/webhook/nexum-contact). Then, in dsf-advisors/main.js, change one line in the form handler:

// in initForm(), the fetch call:
- var res = await fetch("https://formsubmit.co/ajax/" + FEMAIL, {
+ var res = await fetch("https://your-n8n-host/webhook/nexum-contact", {
    method: "POST",
    headers: { "Content-Type": "application/json", "Accept": "application/json" },
    body: JSON.stringify({ intent, name, firm, email, phone, message })
  });

Nothing else changes — the form already sends JSON, and the workflow returns { "success": true }, which is exactly what your existing success check looks for.

Tip: paste the webhook URL into a small constant at the top of main.js (e.g. var FORM_ENDPOINT = "…") so it's easy to change later.
6Activate & test
  • Toggle the workflow Active (top-right in n8n).
  • Submit your own contact form once.
  • You should get an email with the lead + a Claude-drafted reply, and the form should show its normal "Message sent" confirmation.
  • If something fails, open the workflow's Executions tab in n8n — it shows exactly which node errored.
The 3 things only you can do
  1. Run n8n (Cloud account or self-host) — I can't host it for you.
  2. Paste your Anthropic API key into the Claude node — I never see or store your key.
  3. Connect your email and set the destination address.
✓Good to know
  • Model & cost: the workflow uses claude-opus-4-8 (highest quality). For a short auto-reply you can switch the model field to claude-haiku-4-5 to cut cost — that's your call.
  • Do more: n8n can also add the lead to Google Sheets, ping you on WhatsApp/Slack, or auto-send the drafted reply to the client — just add nodes after the Claude step.
  • Auto-reply to the client: add a second Gmail node that sends {{ $json.content[0].text }} to {{ $('Webhook (form submission)').item.json.body.email }}. (Review-first is safer to start.)
